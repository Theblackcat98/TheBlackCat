## What it is

The Aspect Ratio & Resize Calculator is a client-side tool that simplifies common image tasks. It calculates simplified aspect ratios (e.g. 1920x1080 becomes 16:9), calculates megapixels, and features preset dimensions for standard outputs like HD video, social square images, and A4 print.

## How it works

The tool features an interactive crop preview window. By uploading an image and selecting a target dimension or ratio, a crop window overlaid on the image can be dragged into position. A live math panel shows the crop window scale factor and total pixels lost to cropping.

The final cropped area can then be exported, resized exactly to the target dimension, right from the browser. No server is involved and user data stays completely local.
