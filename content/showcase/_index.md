Tools are things that run. This is the other half of the workshop: artifacts built to be **looked at**. Each one is a single self-contained file — no framework, no network call, no plugin — so a piece that opens on this page opens identically on its own.

Everything here is drawn as a cutaway axonometric on a drafting sheet: ink-and-wash surfaces, one light direction, and the structure opened up rather than hidden. Drag to orbit, scroll to zoom, double-click to reset the view.

Each card opens the piece full-bleed with a write-up underneath: what it is, what was drawn, and how it is built.
