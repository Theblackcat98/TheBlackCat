## Why I saved this

Part of the ArtCraft suite of pure-Rust Adobe clones — the InDesign equivalent (page layout and publishing). Repo had no description; the README confirms the target.

## Notes

- Page layout and publishing; clean-room reimplementation of **Adobe InDesign** (~900 stars, Oct 2026).
- Native on macOS, Windows and Linux; in the browser via WebAssembly.
- Agent-drivable over MCP (README badge).
- Rust. Dual-licensed MIT / Apache-2.0.
- Youngest/smallest of the seven Adobe clones by stars.
- Siblings: PhotoCraft, LightCraft, FilmCraft, VectorCraft, EffectCraft, PdfCraft.
