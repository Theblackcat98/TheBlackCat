A single-page gallery of Mermaid diagram types: flowcharts and sequence diagrams through to architecture, Sankey, radar and treemap — each type with a working rendered example and the source that produced it, so a diagram can be lifted straight into a document.

## Read it

[Open the gallery](/mermaid-gallery/) — the full gallery as a standalone page, with a searchable index of diagram types.

## What is inside

- **Twenty-three diagram types** — the Mermaid v11 set, each with a working example and copyable source.
- **Searchable index** — filter the diagram types by name or category.
- **Scope note** — the examples were syntax-checked with Mermaid 11.17.2. ZenUML is not included (it needs an experimental configuration); the final "Info" example is a diagnostic showing the Mermaid version currently running.

## Notes

- The page is a static HTML file served straight from the site: `static/mermaid-gallery/index.html`.
