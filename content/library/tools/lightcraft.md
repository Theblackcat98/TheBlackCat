## Why I saved this

Part of the ArtCraft suite of pure-Rust Adobe clones. Notable for shipping an MCP server — the whole app is drivable end to end by AI agents.

## Notes

- Photo library and raw development; clean-room reimplementation of **Adobe Lightroom** (~2.8k stars, Oct 2026).
- Native on macOS, Windows and Linux; in the browser via WebAssembly.
- MCP server included: the README markets it as drivable end to end by AI agents.
- Pure Rust. Dual-licensed MIT / Apache-2.0. Status: "young and moving fast" (roadmap in repo).
- Siblings: PhotoCraft (Photoshop), FilmCraft, VectorCraft, EffectCraft, DesignCraft, PdfCraft.
