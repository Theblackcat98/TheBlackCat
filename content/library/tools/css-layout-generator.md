## What it is

The CSS Layout Generator is an interactive visual builder. You toggle between CSS Grid and Flexbox, adjust alignment properties, columns, and gaps via a sidebar, and watch the container update in real-time. It simultaneously generates the exact CSS required to achieve the layout.

## Why it's useful

Modern CSS layouts are powerful but the syntax (`justify-content` vs `align-items`, `auto-fit` vs `auto-fill`) can be hard to memorize.

- **Visual feedback:** Instantly see the difference between `space-between` and `space-evenly`.
- **Responsive defaults:** Includes standard responsive Grid patterns like `repeat(auto-fit, minmax(...))` out of the box.
- **Copy-paste ready:** The generated CSS is minimal and un-opinionated, ready to be pasted directly into your stylesheet.
