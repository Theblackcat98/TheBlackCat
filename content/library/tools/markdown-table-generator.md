## What it is

The Markdown Table Generator/Formatter is a client-side utility that takes CSV, TSV, or messy Markdown tables and instantly converts them into perfectly padded, monospaced Markdown tables.

## Why it's useful

Writing tables in Markdown by hand is tedious. Aligning the columns is even worse. This tool automates the process.

- **Instant alignment:** Makes raw Markdown tables highly readable in source code by padding columns dynamically.
- **Data import:** Easily convert spreadsheet data (CSV or TSV) into a static Markdown table.
- **Client-side only:** Fast, and guarantees your data doesn't leave your browser.
