    Output

    robots.txt asks well-behaved crawlers to stay away. It is not access control, and a blocked URL can still appear in search results if other sites link to it. Use authentication for anything private. Crawler names change; check each vendor's documentation.

    Test a path

    Uses the longest matching rule, with Allow winning ties, and supports * and $ as in RFC 9309. It tests the groups above, not a live site.

    sitemap.xml

    Search engines largely ignore changefreq and priority. An accurate lastmod is the useful one; leave it off if you cannot keep it truthful.
