    Mermaid quick reference
    
          
        
    
      
    
      
    
        
    
          
    
            
    The first line picks the diagram
    
            
    Every diagram starts with a keyword that tells Mermaid what to draw.
    
            
    
              
    flowchart TD
    Flowchart, top down
    
              
    sequenceDiagram
    Messages over time
    
              
    classDiagram
    Types and relations
    
              
    stateDiagram-v2
    States and transitions
    
              
    erDiagram
    Data model
    
              
    gantt
    Schedule
    
              
    pie
    Pie chart
    
              
    mindmap
    Indented idea tree
    
            
    
            
    
              
            
    
          
    

          
    
            
    Direction codes
    
            
    Add a direction after flowchart to set which way it flows.
    
            
    
              
    TB / TD
    Top to bottom
    
              
    BT
    Bottom to top
    
              
    LR
    Left to right
    
              
    RL
    Right to left
    
            
    
            
    State and class diagrams use direction LR on its own line.
    
          
    

          
    
            
    Flowchart node shapes
    
            
    
              
    A[Text]
    Rectangle
    
              
    A(Text)
    Rounded
    
              
    A([Text])
    Stadium
    
              
    A[[Text]]
    Subroutine
    
              
    A[(Text)]
    Database
    
              
    A((Text))
    Circle
    
              
    A{Text}
    Decision
    
              
    A{{Text}}
    Hexagon
    
              
    A[/Text/]
    Parallelogram
    
            
    
          
    

          
    
            
    Arrows and edge labels
    
            
    
              
    A --> B
    Arrow
    
              
    A --- B
    Line, no arrowhead
    
              
    A -.-> B
    Dotted arrow
    
              
    A ==> B
    Thick arrow
    
              
    A <--> B
    Both directions
    
              
    A --o B / A --x B
    Circle or cross end
    
              
    A -- yes --> B
    Label in the link
    
              
    A -->|yes| B
    Label after the arrow
    
              
    A ---> B
    Extra dash, longer link
    
            
    
          
    

          
    
            
    Sequence diagram essentials
    
            
    
              
    participant A as Alice
    Name a lifeline
    
              
    actor U as User
    Stick figure
    
              
    A->>B: Hi
    Solid message
    
              
    B-->>A: Hello
    Dashed reply
    
              
    A-)B: Event
    Async message
    
              
    A->>+B / B-->>-A
    Activate, deactivate
    
              
    Note over A,B: Text
    Note across lifelines
    
              
    alt / else / end
    Branches (also loop, opt, par)
    
              
    autonumber
    Number the messages
    
            
    
          
    

          
    
            
    Good habits
    
            
    
              
    A["Total (USD)"]
    Quote labels that contain punctuation
    
              
    %% a note
    Comments go on their own line
    
              
    End not end
    Lowercase “end” as a node breaks flowcharts
    
              
    title: My plan
    A title in --- front matter also names your exports
    
            
    
            
    Keep ids short and put the wording in labels. One statement per line makes errors easy to find.
    
          
    

          
    
            
    Keyboard shortcuts
    
            
    
              
    
                
    Render now
    Ctrl Enter
    
                
    Jump to the error line
    F8
    
                
    Tidy code
    Alt Shift F
    
                
    Indent / outdent
    Tab / Shift Tab
    
                
    Leave the editor with the keyboard
    Esc then Tab
    
                
    Save draft now
    Ctrl S
    
              
    
              
    
                
    Pan the preview
    ← ↑ ↓ →
    
                
    Zoom in / out
    + / −
    
                
    Fit to view
    0
    
                
    Reset to 100%
    1
    
                
    Fullscreen preview
    F
    
                
    Resize panes (on the divider)
    ← →
    
              
    
            
    
            
    Preview shortcuts work while the preview has keyboard focus.
