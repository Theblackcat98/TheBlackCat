Press Ctrl/⌘ + Enter in the input to format. Formatting only moves whitespace around: string literals, quoted identifiers and comments come through untouched. Minify is a small hand-rolled pass that collapses whitespace outside string literals and comments, so it also works when the formatter library cannot be loaded. Formatting itself is done by the sql-formatter library, loaded from the jsDelivr CDN; everything runs client-side and your SQL is never sent anywhere.
