## Why I saved this

Part of the ArtCraft suite of pure-Rust Adobe clones — the Acrobat equivalent, and the one with the most obvious everyday utility.

## Notes

- The PDF workbench; clean-room reimplementation of **Adobe Acrobat** (~2.2k stars, Oct 2026).
- Read, organize, combine, split and secure PDFs; README shows threaded comments and an all-tools panel.
- "No account, no telemetry" per the README badges.
- Rust; native on macOS, Windows, Linux, FreeBSD, plus a web build.
- Dual-licensed MIT / Apache-2.0.
- Renamed from `printcraft` — the old URL 301-redirects here (Oct 2026).
- Siblings: PhotoCraft, LightCraft, FilmCraft, VectorCraft, EffectCraft, DesignCraft.
