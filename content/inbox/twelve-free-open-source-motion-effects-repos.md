## Why I saved this

A ready-made toolkit list for programmatic motion work, saved from an X post by m4lka (@m4lkxx, posted Oct 30, 2026). The post frames the list as libraries to hand to a coding model (it names Opus 5.5) instead of paying for motion-design work — the value here is the repo list itself, each with a one-line job.

## Notes

The twelve repos, as listed in the post:

- [WebGL-Fluid-Simulation](https://github.com/PavelDoGreat/WebGL-Fluid-Simulation) — fluid smoke that follows the cursor
- [postprocessing](https://github.com/pmndrs/postprocessing) — glitch, bloom, and chromatic aberration effects
- [tsParticles](https://github.com/tsparticles/tsparticles) — particle bursts and confetti
- [Flubber](https://github.com/veltman/flubber) — morphing one shape into another
- [GSAP](https://github.com/greensock/GSAP) — animation engine, used in the post for kinetic typography
- [ShaderGradient](https://github.com/ruucm/shadergradient) — animated mesh gradients
- [three.js](https://github.com/mrdoob/three.js) — 3D in the browser
- [Rough.js](https://github.com/rough-stuff/rough) — hand-drawn, sketch-style graphics
- [Hydra](https://github.com/hydra-synth/hydra) — live-coded visuals that react to audio
- [Theatre.js](https://github.com/theatre-js/theatre) — timeline-based motion and camera animation
- [Blender](https://github.com/blender/blender) — full 3D renders, shatter effects, and real lighting
- [LYGIA](https://github.com/patriciogonzalezvivo/lygia) — shader library (noise, liquid-chrome style effects)

The post embeds the author's earlier Oct 20 post pointing to a full motion-design guide ("Motion Design with Opus 5.5: Direct It Like a Studio, Check It Like an Engineer"). The attached video wasn't playable when this was read, so it isn't described here.
