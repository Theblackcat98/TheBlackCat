A design study for llama-deck

The terminal rewards restraint.

The strongest TUIs feel dense, calm, and unmistakably native to the character grid. Their polish comes from hierarchy, alignment, semantic color, and instant response—not from adding more chrome.

9 sections · about a 10-minute read

Method. This study combines terminal-community discussions around r/unixporn aesthetics, a local aggregation of Nick’s starred repositories extracted September 11, 2026, and a static review of llama-deck’s src/ui layer on September 15, 2026. The application was not run live.

Ten rules of a convincing TUI

High-confidence qualitative patterns repeated across independent community discussions. They were not counted as a formal survey.

Information first. Decoration last. Chrome should frame the work, then get out of the way.

01

Honor the grid#

Compose in character cells. Don’t transplant desktop widgets into a keyboard-first surface.

02

Make color mean something#

Use one accent, dimmed chrome, and semantic states rather than a 16-color rainbow.

03

Border selectively#

Thin rounded borders can signal focus; whitespace and dividers should do most of the structural work.

04

Keep the map stable#

Fixed panes, one clear focus, and a persistent breadcrumb reduce the user’s cognitive load.

05

Use glyphs as texture#

Nerd Font icons accelerate scanning, but every icon needs a clean ASCII fallback.

06

Align ruthlessly#

Right-align numbers, hold fixed column widths, and keep content away from borders.

07

Teach through the footer#

A one-line contextual hint bar plus ? help makes the interface self-explanatory.

08

Reveal depth on demand#

Keep the default view quiet; surface power features only when context makes them useful.

09

Move with purpose#

Smooth graphs and live watch states should communicate change, never merely decorate.

10

Use familiar grammar#

Vim-style navigation, mnemonic single keys, / search, q quit, and ? help.

llama-deck has strong bones—and too many frames

The review covered the React shell, screens, components, and themes. This is code-level evidence, not a live usability test.

Current hierarchy
Header boxfull border + app title
Tab barglobal navigation
Screen paneborder + title when focused
Section boxesstatus · meters · throughput · slots

Four simultaneous chrome layers compete with the telemetry they are meant to support.

01

Chrome overload

Drop the header, screen-pane, and footer boxes. Reserve borders for overlays and the single focused widget.

02

Titles shout

“SERVER TELEMETRY,” “STATUS,” and “METERS” use volume where dimmed title case would create calmer hierarchy.

03

The footer spends three rows on one line

Make it borderless and contextual. Keep ? as the complete reference.

04

Gauges leave precision on the table

Fixed 24-cell bars use only full blocks. Scale with width, add eighth-block resolution, and color thresholds semantically.

05

Help is not yet safely modal

The fixed 76-column overlay can overflow smaller terminals. Center it, clamp it, and dim the backdrop.

06

Iconography is missing

Add Nerd Font glyphs for tabs, file types, and states—with ASCII fallbacks and a support check.

Keep these foundations

  • Debounced resize relayout, degradation below 100×30, virtualized tables, and ring-buffered telemetry.
  • Command palette, ? help, footer hints, and a one-owner focus engine.
  • Truecolor themes, OSC 52 clipboard support, braille spinners, sparklines, and golden-frame snapshots.

Themes should preserve meaning

Five themes exist in code: TokyoNight, Catppuccin, Gruvbox, Cyberpunk, and Matrix. The README also claims Nord and Monokai, which creates documentation drift.

Repair Catppuccin

fgBright is Rosewater #f5e0dc; use a near-white Text role in the #cdd6f4 family.

Rework the joke themes

Cyberpunk is harsh for sustained reading. Matrix flattens success and warning into similar greens and makes muted text nearly invisible.

Add taste-aligned options

Rose Pine matches the star signal. Nord and Everforest also broaden the serious, low-fatigue set.

CyberpunkBody text #00f0ff on #0d0e15; muted #4a5171 is weak against that background.
MatrixSuccess #00ff41 and warning #a3ff00 are hard to distinguish; muted #003b00 nearly disappears on #050b05.
Test ruleAdd programmatic contrast checks, aiming for a WCAG-like minimum of 4.5:1 for foreground/background pairs.

A compact design contract

Use this as the review lens for every new screen.

Keep

  • Information-dense default views
  • One active accent and clear semantic states
  • Stable panes and a visible breadcrumb
  • Right-aligned numbers and fixed columns
  • Contextual hints plus full help
  • Fast, differential redraws

Avoid

  • A border around every region
  • Desktop-widget cosplay
  • Hardcoded clashing color
  • Glyphs without fallbacks
  • Text touching frames
  • Flicker and full redraws

Evidence and limits

Each conclusion in this study belongs to one of these three evidence streams.

Community aesthetic

Search-grounded synthesis of Lobsters discussions, Hacker News threads, and unixporn-adjacent coverage. Repeated patterns are treated as qualitative consensus, not measured prevalence.

Starred repositories

llama-deck review

Static code review of src/ui on September 15, 2026. No live interaction or rendered-frame validation was part of the research pass.
