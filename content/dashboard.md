Every public, non-fork, non-archived repository I own, in one place. The todo list for each repo is its open GitHub Issues — the single source of truth — and the health score checks the basics: a description, at least three topics, a README with some substance, a license, and a push in the last 90 days. Synced nightly from the GitHub API; private repositories are never shown here.
