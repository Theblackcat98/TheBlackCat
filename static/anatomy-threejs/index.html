Live exhibits · six machines

Anatomy in Three.js

The same idea as the Anatomy figures — cutaway machines on test rigs, mechanism running — rebuilt in real 3D. Orbit them, crank them by hand, pull them apart and slide the section through. Every figure is a single HTML file with Three.js vendored alongside: no framework, no network calls. Each opens in the Light drawing theme; Dark, Paper, Sepia and Blueprint are on the figure's own pills.
