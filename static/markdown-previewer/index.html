Markdown & Hugo Studio

← All tools

Four of the site's writing tools in one studio: draft a post with a live preview, run the frontmatter doctor on it, convert JSON into Hugo front matter, and build Markdown tables. Nothing is uploaded.

The Preview tab runs the same frontmatter linter as the Frontmatter tab — one set of rules, checked in both places.

Preview

Checks

    Rules come from this site's contributor guide: contenttype not type, source not url, headings starting at ##, a language on every code fence, and the callout and anatomy shortcodes. The preview is an approximation; the live site renders raw HTML and syntax-highlights code.

    Frontmatter Doctor

    Paste a Markdown file or just its frontmatter to check it against the site's rules — the same linter the Preview tab runs. Errors break the build or the taxonomy; warnings are drift worth fixing.
