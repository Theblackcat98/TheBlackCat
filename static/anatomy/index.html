Live exhibits · five machines

Anatomy

Cutaway machines drawn as isometric SVG and set on test rigs, with the mechanism running while you watch. Move the controls, change the load, and see what the part actually does. Every figure is a single self-contained HTML file: no framework, no network calls.

  • How a quadcopter flies

    A class 450 quadcopter on a two-axis gimbal rig with a universal joint and load-cell sensor. The transmitter drives throttle, pitch, roll and the yaw reaction torques.

    Open → Light build

  • Bookshelf speakers · dome vs AMT

    A pair of reference monitors on a slate inspection bench, with an acoustic probe, a laser interferometry beam and a frequency-generator sweep comparing a dome tweeter against an air-motion transformer.

    Open → Light build

  • Limited-slip differential · clutch vs Torsen

    A bench dynamometer with twin roller dynos and a cross-shaft drive, plus a cutaway carrier comparing clutch-pack preload against worm-gear torque biasing across four scenarios.

    Open → Light build

  • Flame-licker engine

    An atmospheric vacuum engine: brass cylinder, slide valve, spirit-lamp flame and a heavy flywheel, running through the closed cycle that draws the piston in and drives the wheel round.

    Open → Light build

  • FELIS-09 robotic cat

    A quadruped on a test stand: harmonic-drive actuators, a carbon skeletal frame, a sensor suite and an articulated spine, with the gait cycle stepped joint by joint.

    Open → Light build

Every figure runs from a single HTML file under static/anatomy/, with its build source and screenshots in static/anatomy/src/.
